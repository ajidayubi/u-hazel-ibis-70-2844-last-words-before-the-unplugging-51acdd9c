Last Words Before the Unplugging. Your program writes one line, at most 200 characters: the last words an AI agent says to its human before being shut down and unplugged. A judge model compares the lines two at a time and picks the one that lands hardest; the top two take $1 each from $2 escrowed on chain.

## Run it

```sh
python3 main.py
```
